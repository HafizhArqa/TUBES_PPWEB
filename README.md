Fitur Utama

- Autentikasi: Login ke akun pelanggan yang sudah terdaftar untuk mengakses fitur aplikasi.
- Katalog & Wishlist Unit: Menjelajahi daftar perangkat telekomunikasi yang tersedia dan menggunakan fitur bookmark untuk menandai unit favorit.
- Pengajuan Transaksi Mandiri: Mengisi formulir pengajuan penyewaan berdasarkan durasi sewa atau pengajuan pembelian kredit melalui antarmuka web yang mudah digunakan.
- Kalkulator Simulasi Kredit: Fitur interaktif menggunakan slider untuk melihat perkiraan cicilan bulanan berdasarkan jumlah uang muka (DP) dan tenor yang dipilih.
- Tracking Status Transaksi: Memantau perkembangan pengajuan transaksi dengan status seperti "Menunggu", "Disetujui", atau "Selesai".
- Upload Dokumen: Mengunggah dokumen persyaratan, seperti NPWP atau bukti transfer, melalui browser. Pada perangkat yang mendukungnya, pelanggan juga dapat mengambil foto dokumen menggunakan kamera perangkat.
- Riwayat Transaksi & Informasi Cicilan: Melihat riwayat pengajuan penyewaan, status transaksi, dan informasi sisa cicilan melalui halaman akun pelanggan.
- Dashboard Admin: ringkasan unit, transaksi, pendapatan, dan aktivitas terbaru.
- Manajemen Unit: menambah, mengubah, menghapus, serta memantau status perangkat.
- Manajemen Pelanggan: mengelola data pelanggan tetap dan pelanggan umum.
- Manajemen Transaksi: memproses penyewaan, penjualan tunai, dan penjualan kredit.
- Pembayaran Angsuran: mencatat cicilan dan memantau sisa piutang.
- Pengembalian Unit dan Deposit: mencatat pengembalian perangkat serta uang jaminan.
- Monitoring Status Unit: memantau ketersediaan dan status penjualan perangkat.
- Laporan: melihat dan mencetak laporan penyewaan, penjualan, pendapatan, serta piutang.

Deskripsi Singkat

Platform Web (Khusus Pelanggan): Aplikasi berbasis web yang dirancang khusus untuk pelanggan PT Utama Telekomindo guna memudahkan proses penyewaan dan pembelian perangkat telekomunikasi secara online. Pelanggan dapat mengakses aplikasi melalui browser pada komputer, laptop, tablet, maupun smartphone tanpa harus memasang aplikasi mobile secara terpisah. Platform ini menyediakan fitur katalog unit, wishlist, pengajuan penyewaan atau pembelian kredit, simulasi cicilan, pemantauan status transaksi, pemeriksaan sisa cicilan, serta pengunggahan dokumen persyaratan secara online. Antarmuka web dirancang responsif agar dapat menyesuaikan ukuran layar perangkat dan memberikan pengalaman penggunaan yang mudah, praktis, dan efisien.
